# Сценарії ситуацій — Правовий контакт

Тут зібрані типові ситуації контакту з поліцією для MVP.

Кожен сценарій містить:
- опис ситуації
- права людини
- обов’язки поліцейського
- що обов’язково фіксувати
- посилання на норми
- практичні рекомендації

**Важливо:** тексти базуються на чинному законодавстві. Перед використанням у продукті завжди звіряйте актуальну редакцію на zakon.rada.gov.ua.
