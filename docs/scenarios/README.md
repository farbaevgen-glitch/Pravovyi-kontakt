# Сценарії ситуацій — Правовий контакт

Тут зібрані типові ситуації контакту з поліцією.

Кожен сценарій містить:
- короткий опис ситуації
- права людини
- обов’язки поліцейського
- що обов’язково фіксувати
- посилання на норми закону
- рекомендації щодо подальших дій (у т.ч. скарга)

**Важливо:** тексти базуються на чинному законодавстві станом на перевірку. Перед використанням у продукті звіряйте актуальну редакцію на zakon.rada.gov.ua.
