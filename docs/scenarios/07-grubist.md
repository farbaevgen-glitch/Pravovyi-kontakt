# Сценарій 7. Грубість, образа, погроза з боку поліцейського

**Дата підготовки:** 01.09.2026  
**Статус:** чернетка для MVP

## Опис ситуації

Поліцейський грубіянить, ображає, підвищує голос, погрожує, використовує нецензурну лексику або поводиться негідно.

## Права людини

- На гідне ставлення.
- Вимагати ідентифікації.
- Фіксувати поведінку (аудіо/відео).
- Подати скаргу на порушення етики та службової дисципліни.

## Обов’язки поліцейського

- Дотримуватися Правил етичної поведінки поліцейських.
- Ідентифікуватися (ст. 18).
- Не допускати образ, приниження і грубощів.

## Що фіксувати

1. Номер жетона, ПІБ, посада.
2. Точні слова / дії (краще на відео/аудіо).
3. Час, місце, свідки.
4. Контекст ситуації.

## Посилання

- Закон «Про Національну поліцію» — ст. 18, 20  
  https://zakon.rada.gov.ua/go/580-19
- Правила етичної поведінки поліцейських (наказ МВС № 1179 від 09.11.2016)
- Дисциплінарний статут Національної поліції

## Рекомендації

Грубість сама по собі часто є дисциплінарним проступком.  
Найефективніше — мати відео/аудіо + чітко зафіксовані дані поліцейського + свідків. Після цього подавати скаргу до підрозділу внутрішньої безпеки / керівництва та (за потреби) до ДБР або Омбудсмана.
