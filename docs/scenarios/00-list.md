# Пріоритетний список ситуацій для MVP

1. **Зупинка та перевірка документів** — найчастіша ситуація.
2. **Ідентифікація поліцейського** (вимога назватися + жетон + посвідчення).
3. **Доставлення / затримання**.
4. **Відмова прийняти заяву** або зафіксувати повідомлення про злочин.
5. **Застосування фізичної сили або спеціальних засобів**.
6. **Особистий огляд / огляд речей**.
7. **Грубість, образа, погроза** з боку поліцейського.

Ці 7 сценаріїв покривають більшість типових конфліктних контактів і дозволяють побудувати корисний MVP.
