# Правовий контакт

**Відкритий інструмент правової грамотності та прозорих скарг під час контакту з поліцією**

Репозиторій: [farbaevgen-glitch/Pravovyi-kontakt](https://github.com/farbaevgen-glitch/Pravovyi-kontakt)

## Що це

«Правовий контакт» — цифровий інструмент, який допомагає людині в моменті (або одразу після) контакту з поліцією:

1. **Зрозуміти свої права і обов’язки** саме в цій ситуації.
2. **Правильно зафіксувати** ідентифікаційні дані поліцейських (прізвище, посада, звання, номер жетона, номер авто) — дані, які за законом є відкритими під час спілкування.
3. **Сформувати і подати** структуровану офіційну скаргу.
4. **Відстежувати** статус і вимагати змістовної (не формальної) відповіді.
5. Створювати публічну анонімізовану аналітику для підвищення прозорості та довіри.

## Принципи

- Ідентифікація під час контакту — відкрита (ст. 18 Закону «Про Національну поліцію»).
- Скарга має бути правильною, повною і відстежуваною.
- Відповідь має містити конкретні дії, а не лише «розглянуто».
- Прозорість — публічна, але в межах закону.
- Мета — зменшити безкарність через фіксацію, грамотність і публічний тиск.
