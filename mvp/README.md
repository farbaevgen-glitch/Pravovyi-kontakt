# MVP — Правовий контакт

Простий робочий веб-прототип.

## Що вміє

1. Вибір однієї з 7 типових ситуацій
2. Показ прав людини, обов’язків поліцейського і того, що потрібно фіксувати
3. Форма фіксації даних поліцейського (жетон, ПІБ, авто, місце, час тощо)
4. Генерація готового тексту скарги
5. Копіювання тексту одним натисканням

## Як відкрити

Просто відкрийте файл `index.html` у будь-якому сучасному браузері  
(або підніміть локальний сервер).

```bash
# Приклад
cd mvp
python -m http.server 8000
# або
npx serve .
```

Потім відкрийте http://localhost:8000

## Файли

- `index.html` — розмітка
- `styles.css` — стилі
- `app.js` — логіка і дані сценаріїв
