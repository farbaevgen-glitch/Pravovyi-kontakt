# MVP

Тут буде код першого робочого прототипу.

Планований мінімальний функціонал:

1. Вибір / опис ситуації
2. Роз’яснення прав і обов’язків
3. Форма фіксації ідентифікації поліцейських
4. Генерація тексту скарги
5. Збереження / експорт

Технологічний стек MVP буде визначено найближчим часом (орієнтир — простий, швидкий і доступний веб).
