# MVP — Правовий контакт

Тут буде код першого робочого прототипу.

## Планований мінімальний функціонал

1. Вибір / опис ситуації
2. Роз’яснення прав і обов’язків
3. Форма фіксації ідентифікації поліцейських (жетон, ПІБ, авто тощо)
4. Генерація тексту офіційної скарги
5. Збереження / експорт / копіювання

Технологічний стек MVP визначимо на наступному кроці (орієнтир — простий і швидкий веб-інтерфейс).
